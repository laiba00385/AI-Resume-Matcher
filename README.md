
# 🤖 AI Resume Matcher

### An AI-Powered Resume Analysis Application Using NLP

## 📌 About the Project
AI Resume Matcher is a beginner-friendly Artificial Intelligence project that compares a user's resume with a job description. It uses Natural Language Processing (NLP) and Machine Learning techniques to calculate text similarity and identify relevant and missing keywords.

## ✨ Features
- Upload resume in TXT format.
- Enter a job description.
- Calculate resume matching percentage.
- Identify matching keywords.
- Highlight potentially missing keywords.
- Simple and user-friendly interface.

## 🛠️ Technologies Used
- Python
- Artificial Intelligence
- Natural Language Processing (NLP)
- Streamlit
- Scikit-learn
- TF-IDF
- Cosine Similarity

## ⚙️ How to Run the Project

**Step 1:** Install the required libraries.

```bash
pip install -r requirements.txt
```

**Step 2:** Run the application.

```bash
streamlit run app.py
```

**Step 3:** Open the application in your browser.

## 🧠 How It Works
1. User uploads or pastes a resume.
2. User enters a job description.
3. The application processes both texts.
4. TF-IDF converts text into numerical vectors.
5. Cosine Similarity calculates the matching score.
6. Results display matching and potentially missing keywords.

## 🎯 Project Objective
The main objective is to help job seekers understand how closely their resumes match job descriptions and identify areas for improvement.

## 🔮 Future Improvements

## ⚠️ Disclaimer
The matching percentage is a text similarity estimate, not a measure of a candidate's actual skills or job suitability.
